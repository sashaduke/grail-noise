# grail-noise

Coherent noise for [Grail](https://github.com/graillang/grail): a port of
[FastNoiseLite](https://github.com/Auburn/FastNoiseLite) 1.1.1 that reproduces the C++ results
**bit for bit**.

Covered: 2D OpenSimplex2, OpenSimplex2S, Cellular (all distance functions and return types),
Perlin and Value noise; None, FBm and Ridged fractals (gain, lacunarity, weighted strength);
2D OpenSimplex2 domain warp, single and progressive; 3D OpenSimplex2S with None and FBm.

```grail
use noise;

fn main() {
    mut n = noise::new(1337);
    noise::set_noise_type(&mut n, noise::NOISE_OPENSIMPLEX2S);
    noise::set_fractal_type(&mut n, noise::FRACTAL_FBM);
    noise::set_fractal_octaves(&mut n, 5);
    println(noise::get(&n, 12.5, -3.25));                                   // 2D
    println(noise::get3(&n, noise::Point3 { x: 1.0, y: 2.0, z: 3.0 }));      // 3D
    p := noise::warp(&n, noise::Point { x: 10.0, y: 20.0 });                // domain warp
    println(p.x);
}
```

Coordinates are `f64` and all other arithmetic is `f32`, matching the reference instantiated with
double coordinates.

## Verification

`tests/reference/noise_cases.cpp` evaluates 17 configurations at 50 coordinates each with the C++
library and writes `tests/cases.grl`, which recomputes them and compares the exact binary32 (or,
for warps, binary64) bits. `noise_tables.grl` is generated by `noise_tables.cpp` so lookup tables
and folded float constants carry the same bits as the C++.

```sh
GRAIL=/path/to/grail ./test.sh
```
